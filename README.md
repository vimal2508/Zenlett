# Zenlet — Separate HTML Pages

Each page is a separate file:
- index.html — Home
- services.html — Services
- how-it-works.html — How it works
- about.html — About
- security.html — Security
- faq.html — FAQ
- contact.html — Contact
- login.html — Login
- register.html — Register
- terms.html — Terms & Conditions
- dashboard.html — Dashboard preview

Shared files: styles.css and app.js.

## GitHub upload
Upload all files from this folder to the repository root. Keep all HTML files, styles.css and app.js at the same level. Do not put these page files inside src.

## Important
This is a static frontend starter. Login, registration, contact form delivery, KYC, wallet, deposits, withdrawals and financial transactions are not connected or enabled. Do not accept real money or sensitive identity documents through this starter. Obtain appropriate legal, privacy and security review before launch.
